# Apple TV Content Analysis Dashboard

## 📊 Project Overview
This project is an interactive Power BI dashboard created to analyze Apple TV movies and shows.

## 🔍 Key Insights
- Total Titles: 170
- Total Genres: 97
- IMDb rating analysis
- Movie vs Series distribution
- Release year trends
- Genre-based analysis

## 🛠 Tools Used
- Power BI
- Data Cleaning
- Data Modeling
- Data Visualization
- SQL (basic)
